## 📖 Descripción

Repositorio dedicado al aprendizaje de **Python**, desarrollado durante el módulo de Programación de Servicios y Procesos de 2.º de DAM.

Contiene ejercicios prácticos, apuntes, actividades y material teórico sobre programación con Python, estructuras de datos, algoritmia y resolución de problemas.

El objetivo es recopilar los conocimientos adquiridos durante el curso, organizar las actividades realizadas y llevar un seguimiento del aprendizaje del lenguaje.

---

## 🐍 ¿Qué es Python?

**Python** es un lenguaje de programación de alto nivel, interpretado y multiparadigma, diseñado para facilitar la legibilidad del código y el desarrollo de aplicaciones.

Se caracteriza por utilizar tipado dinámico y fuerte, disponer de una sintaxis sencilla y contar con un amplio ecosistema de bibliotecas.

Es utilizado en ámbitos como el desarrollo backend, la automatización de tareas, la inteligencia artificial, la ciencia de datos y el desarrollo de herramientas.
